NexusVox 1.0.0 - the first free release: installer, CPU-only dictation and a rebuilt dashboard

NexusVox 1.0.0 is a Windows app that turns speech into text on your own PC. This release adds a signed installer, runs the speech model on the CPU with no Docker and no GPU, records meetings, and rebuilds the dashboard around a Home page and a first-run setup. The app is free and source-available under the PolyForm Noncommercial License 1.0.0.

Download and install
- Download `NexusVox-Setup.exe` from the assets below. It is per-user and needs no administrator rights.
- Requires Windows 10 (version 2004 or newer) or Windows 11, 64-bit.
- The speech model downloads on first use (about 670 MB for Parakeet on the CPU). An NVIDIA GPU is optional and makes dictation much faster.
- The installer is signed with the NightShift AI GmbH code-signing certificate. Windows SmartScreen builds trust per download, so it can still show "Windows protected your PC": click More info, then Run anyway.

Installer and platform
- Windows installer built with Inno Setup, with an uninstaller that keeps your data unless you ask it to remove it (#209, #187, #183)
- Runs on Windows 10 version 2004 and newer as well as Windows 11 (#362)
- Check for updates in the sidebar: it asks GitHub for the newest release only when you click, sends nothing about you or your PC and downloads nothing (#357)
- New app, tray, dashboard and installer icons (#219, #312)
- Starting NexusVox from the Start menu opens the dashboard; the Windows autostart stays in the tray (#301)
- A busy dashboard port or a second running copy is handled with a clear message (#191)
- The installer ships an LGPL-only FFmpeg; its source is attached to this release (#354, #356, #353)

Dictation
- Parakeet runs in-process on the CPU (ONNX, int8) with no Docker and no GPU, and takes over when the GPU server is not available (#184, #315)
- Ctrl+Win is the default hotkey, in Hold or Toggle mode; Escape cancels, a recording stops after 10 minutes, and a blank hotkey is rejected (#217, #223, #244)
- Dictated numbers, ordinals and voice commands are typed as spoken, with "numbers as digits" on by default (#208, #214, #331)
- The spoken language is always detected, English and German are both recognised, and the fixed language setting is gone (#195)
- Speech models are trimmed to Parakeet, Whisper Large V3 Turbo and a slot for your own server (#196)
- Optional live waveform at the bottom of the screen as dictation feedback (#105)
- Polish keeps its answer in the language of the selected text, can reload its model after a timeout, and the language model stays loaded while NexusVox runs (#185, #280, #286)
- Assign a fast model and a main model to different tasks, and pick the language model from a list of what is installed (#291, #204)
- Cleanup is greyed out without a CUDA GPU and can be switched on for CPU use (#125, #174)
- Stray Alt and Win key-ups no longer open app menus (#188, #101)
- A recording without audio is skipped instead of transcribed (#308)

Meetings and files
- Meeting recording for your microphone and the system audio, with a meeting hotkey, one Me/Others transcript, numbered speakers and a live transcript while it records (#87, #88, #89, #103, #111)
- Optional: keep only the merged meeting audio, leave dictation out of meeting transcripts, rename and delete meetings and uploads (#130, #91, #133)
- Meetings and Upload are one two-pane Recordings tab (#270)
- Export uploads as TXT, SRT and VTT (#96)
- Speaker detection falls back to Parakeet for meetings and uploads (#306)
- Large uploads stream to disk and convert window by window (#349)

Dashboard
- A Home start page, a four-step first-run setup, one Settings page per section, a settings search and icons on the tabs (#272, #273, #271, #215, #261)
- Analytics reworked into an Overview and a Your week view, with dictation per app, voice commands, polish, accuracy and dictionary stats and local days in every chart (#281, #117, #135, #131, #123, #251)
- Saved custom LLM servers with their model lists (#269)
- Send feedback from the dashboard, with an optional log (#197, #259)
- Back and forward work across dashboard pages (#283)
- Logs go to a rotating file, with audio logging summarised per recording (#118, #289)
- Guided Ollama install when the language model is missing, and a yellow warning when a hotkey contains Alt (#226, #224)
- Experimental features (OS commands, the Edit tab, Fill from GitHub, the Dev page) are hidden behind `[experimental]` (#186)

Extensions

Upgrade notes
**Updating:** run the new installer. If you run NexusVox from source, run `pip install -e .` after `git pull`, because 1.0 adds new dependencies.
- The Docker GPU server is optional; the installed app runs without it.
- Database columns are migrated automatically on start.
- The extension API is unchanged at version 1 for existing extensions; the new hooks are optional.
