    Dictation

    The everyday basics: how you start a recording, what you speak and what you see while it runs.

    Hotkey

    Current:

    Default is Ctrl+Win. Tick the modifiers you want and optionally pick one key to complete the combo, or click Record and press the combo. A key such as A is swallowed while it is held as part of the combo, so the letter never reaches the app you are dictating into.

    +

    Hotkey Mode

    Hold: record while the keys are held. Toggle: press once to start, press again to stop.

    Switching the mode while a recording runs: Hold to Toggle keeps recording until the next press; Toggle to Hold stops at the next key release.

    Escape cancels a running recording in both modes: nothing is pasted.

    Microphone

    The microphone dictation records from. Applies from the next recording. Meetings have their own microphone under Meetings.

    Feedback

    Sound: the start and stop chimes. Visual: a small live waveform at the bottom centre of the screen while you speak, a short processing state until the text is typed, and a red bar for an error. It never takes focus and ignores the mouse, so your dictation still lands in the app you were in. Meeting recordings never show it.

    Mute Other Apps While Recording

    Mutes every other app's microphone session (Teams, browser calls, ...) while you record, so your dictation is not broadcast to a call, and puts each one back as it was afterwards. An app you muted yourself stays muted. Discord's desktop app ignores this: bind Discord's own Push to Mute keybind to the NexusVox hotkey instead.

    Vocabulary

    Words and phrases NexusVox should know: corrections, text shortcuts and rewrite instructions.

    Correction Dictionary

    Words the model keeps getting wrong. Every match (whole word, any case) is replaced before the text is typed.

    →

    Tip: correcting a recording in the Review tab suggests entries automatically.

    Learn From Edits

    After a paste, NexusVox reads the text field for a while (20 seconds by default, [learn_from_edits].window_s). Words you correct there show up below as suggestions; nothing is added without your OK. Password fields and terminals are never read, and nothing is learned from a dictation that auto cleanup or translation changed.

    Polish Presets

    Instructions you use often, under a short name. Select text, hold the hotkey, tap your polish key and say the name - "prompt engineer", "formal email" - and the stored instruction is used; words after the name are added to it ("formal email, and keep it short"). The default preset applies when you tap the polish key without saying anything. Names in any language; close spellings match.

    Text & Polish

    What happens to the words after you speak them: tidying, rewriting, translating and spoken formatting.

    Paste Last Text Key

    Start a recording with the hotkey, tap this key while every modifier is still down, let go: nothing is transcribed and the text NexusVox pasted last is pasted again.

    Polish Selected Text Key

    Select text, start a recording with the hotkey, tap this key and say what to do ("make it shorter", "mach es formeller") - or nothing for a general polish. A local language model rewrites the selection and pastes it over it; Ctrl+Z in the app undoes it.

    Auto Cleanup

    Tidies every dictation through the same model before it is typed. Light: removes fillers ("um", "äh"), false starts and repeated words, fixes punctuation, keeps your wording. Medium: also grammar, slightly more concise. Adds about half a second with a GPU; while the model is still loading, or when its reply does not look like your text cleaned up, the dictation is typed unchanged. Saved as spoken.

    Translate to English external service

    Sends the transcript to a local translator server and types what comes back. NexusVox does not translate on its own: the server is a separate program you run yourself ([translator] in config.toml). If it does not answer, the original text is typed. The stored transcript stays in the spoken language.

    Voice Commands

    Format injected text with spoken phrases: new line, tab, all caps, symbols, and more (English and German).

    Numbers as Digits

    Convert spoken numbers to digits, English and German: "twenty five" / "fünfundzwanzig" → "25".

    Press Enter Command

    End a dictation with "press enter" / "Enter drücken" to paste the text and then press Enter, e.g. to send a chat message.

    Bypass Symbol Commands

    Skip symbol substitutions without clearing your list. Structural commands still apply. Useful for benchmarking.

    Bypass Structural Commands

    Skip new line, new paragraph, tab and all caps without clearing your list. Useful for benchmarking.

    Structural Commands

    Click to toggle formatting phrases: new line / neue Zeile, new paragraph / neuer Absatz, tab / Tabulator, all caps / alles groß. English and German are always both recognised.

    Symbol Commands

    Click to toggle symbols you want recognised as voice commands. Ambiguous symbols share common English words and may fire accidentally.

    Models

    Which speech model turns your voice into text.

    Transcription Model

    Select which model to use for speech-to-text.

    Language model (LLM)

    Used by Cleanup, Polish and upload cleanup. Models that are not installed are greyed out with their download size; nothing downloads until you confirm it. It shares the GPU with the speech model - mind the VRAM.

    Noticeable latency on this hardware: Cleanup and Polish are slower.

    Advanced: language models per task

    Use different models per task

    Off: the language model above does everything. On: a small, fast model cleans up your dictations, and the model above becomes the main model for everything else, such as Polish, uploaded files and extensions. Both stay loaded while NexusVox runs - mind the VRAM.

    Fast model

    Picked from the same list as the main model: Ollama, your saved servers and the main model's server. Until you pick one, the main model does its tasks too.

    Which model does what

    Extensions and Pro features (snippets, summaries, search and ask) always use the main model.

    Switching GPU-backed models restarts Docker containers and reloads weights. CPU (in-process Whisper) switches reload the model directly — may take 5–20s on first load.

    Model Overview

    Custom language model servers

    Add a server you run yourself (Ollama, llama.cpp, LM Studio, vLLM or any OpenAI-compatible API) by its address with the port. NexusVox finds out which API it speaks, saves it, and lists its models in the language model dropdown above.

    Language Model Overview

    Meetings

    Recording calls: how you are named in the transcript, the meeting hotkey and the audio devices.

    Meetings: name for your own voice

    How your microphone's speaker is labelled in meeting transcripts (default Speaker 1). The other participants are numbered on from Speaker 2. Applied when a meeting is transcribed.

    Meeting hotkey

    Starts and stops a meeting from anywhere. It needs a key and at least one modifier, and must not be the dictation hotkey. Documentation: docs/MEETINGS.md.

    +

    Microphone

    Your side of the conversation. Applies from the next meeting.

    Output device

    The device the other participants are played on (it is recorded, not changed). Applies from the next meeting.

    Show the consent hint

    Reminds you to inform all participants before each recording. With it on, the meeting hotkey opens this tab so you can confirm.

    Leave dictation out of the meeting transcript

    Text you dictate during a meeting is also picked up by the microphone. With this on, those words are dropped from the Me part when the meeting is transcribed; the recorded audio stays as it is.

    Store meeting audio

    Keeps one playable recording of the meeting next to its transcript. The two recorded tracks are always deleted once the transcript is saved. Off: the playable recording is deleted too. Meetings already stored keep their audio.

    Privacy

    What NexusVox keeps on this computer.

    Store Audio Recordings

    Keeps a WAV file of every recording next to the database (audio/) so you can play it back in the Review tab. Off: only the transcript is saved, nothing is written to disk for the audio. Recordings already stored stay.

    Log File

    NexusVox also writes its log to %LOCALAPPDATA%\NexusVox\logs (one file per day, the last 7 days are kept). Send the file when you report a problem. Dictated text is shortened there to its first 20 characters and its length.

    Log Full Text (debugging)

    Writes what you dictated into the log file in full. Turn it on only to track down a problem, and check the file before you send it. The console always shows full text.

    Advanced

    Rarely needed. The defaults work for most people.

    Compute Device

    CPU runs Whisper in-process with no Docker. GPU enables all models via Docker-backed inference servers.

    Changing the device takes effect after restarting NexusVox.

    Polish In Terminals Too

    Terminals do not tell NexusVox what is selected, so polish copies the selection with Ctrl+C there - which interrupts the running program when nothing is selected. The rewritten text is pasted at the prompt, not over the selection. Off: polish plays the error beep in terminals.

    Nexus OS Commands

    Voice-triggered window management. Say nexus <action> <app> while recording.

    Supported Commands

    Registered Apps

    Edit config.toml under [os_commands.apps] to add or remove apps.

    Feedback & bug reports

    Tell us what works, what you wish for, or what broke.

    Also sent: the NexusVox version, the Windows version and whether this PC runs CPU-only or with an NVIDIA GPU. Nothing is sent until you click Send. Your audio and dictated text never leave this PC.
