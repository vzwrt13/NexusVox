# Configuration reference

Every `config.toml` section and where its dataclass lives (`src/nexusvox/config_sections/`).

`config.toml` (git-ignored) is created in the working directory on first run, from the template at `src/nexusvox/config.example.toml`. The template ships inside the package so an installed wheel can find it; do not move it back to the repository root. Editable settings: first-run setup (`[general].setup_done`, bool: false only in the config created from the template on a fresh install, true when the key is missing, so no existing install sees the setup; the dashboard sets it when the setup is finished or skipped, and the app opens the dashboard on its own at start while it is false), dictation microphone (`[audio].device`, a device name as the dashboard lists it, empty: the system default input; `AudioCapture.start` reads it at every recording), file log (`[general].log_full_text`, bool, default false: dictated text is shortened in the file log), console log level (`[general].log_level`, `DEBUG`/`INFO`/`WARNING`/`ERROR`, default `INFO`, applied at start to the `nexusvox` loggers), injection delay (ms between modifier release and paste), hotkey modifiers, optional key, mode (`hold`/`toggle`) paste key and polish key, audio sample rate/chunk size, inference server URL, transcription model (3 entries in `MODEL_REGISTRY`: `parakeet-tdt-0.6b` (default; GPU via Docker or in-process CPU through ONNX), `whisper-large-v3-turbo` (for languages outside Parakeet's 25 European ones; Docker or in-process CPU); a config that names a removed model falls back to Parakeet on load with one log line; the dashboard model list marks each model as downloaded or not through `model_download_state`; `custom-server`, a user-run server under `[inference.custom]`: url, protocol `http`/`realtime`, model_name — no Docker, contract in `docs/CUSTOM_SERVER.md`), transcription delay, database path, audio storage directory (default `audio/`) and `store_audio` (bool, default true; off saves the transcript only), experimental features (`[experimental]`: `os_commands`, `flag_command`, `dev_tab`, all default false: hidden in v1, their dashboard endpoints not registered), OS commands enabled (bool, default false; needs `[experimental].os_commands`), OS commands apps (name→exe path mapping under `[os_commands.apps]`), assistant forward (`[assistant]` section: enabled bool, host, port, service, timeout_s), os-control command recordings (`[os_control]` section: enabled bool, command_key, host, port, service, timeout_s), voice commands (`[voice_commands]` section: enabled bool, numbers_as_digits bool (default true), structural list + bypass_structural bool, symbols list + bypass_symbols bool, press_enter bool), translate before inject (`[translator]` section: enabled bool, url, timeout_s), mic guard (`[mic_guard]` section: enabled bool, watchdog_s), dictation feedback (`[feedback].mode` `sound`/`visual`/`both`), learn from edits (`[learn_from_edits]` section: enabled bool, window_s), the language model for polish (`[llm]` section: url, protocol `ollama`/`openai`, model, api_key, timeout_s, keep_alive; `[[llm.servers]]`: the custom servers saved in the dashboard, each with name, url, protocol, api_key; an entry without a URL, with an unknown protocol or a repeated URL is dropped on load, and so is an Ollama-protocol entry at `http://127.0.0.1:11434`: Ollama on this PC is a fixed dashboard entry, which also cleans up the copy an earlier version saved), polish in terminals (`[polish]` section: in_terminals bool, default false), auto cleanup (`[cleanup]` section: level `off`/`light`/`medium`, timeout_s), remote mic (`[remote_mic]` section: enabled bool, host, port, token), feedback form (`[support].feedback_form_url`: the dashboard's "Send feedback" button opens it in the browser with the app version, Windows version and hardware tier as URL parameters, `system/feedback_form.py`; defaults to `https://nexusvox.app/feedback`, an empty value hides the button; the app contacts the host only when the user clicks *Send* in the Feedback tab, and only if the URL is https on `nexusvox.app`, `system/feedback_send.py`), meeting recording (`[meeting]` section: modifiers, key, mic_device, output_device, consent_hint bool, leave_dictation_out bool, live_transcript bool, store_audio bool).
