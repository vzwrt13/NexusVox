NexusVox 1.0.2 - install updates from inside the app

NexusVox is a Windows app that turns speech into text on your own PC. Version 1.0.2 is a small release on top of 1.0.1: from now on, updates install from inside the app, and Pip's what's-new tour is easier to follow. NexusVox is source-available under the PolyForm Noncommercial License 1.0.0 and free for personal use.

Download and install
- Download `NexusVox-Setup.exe` from the assets below. It is per-user and needs no administrator rights.
- Requires Windows 10 (version 2004 or newer) or Windows 11, 64-bit.

What changed
- Install updates from inside the app: Install update downloads the new installer, checks its signature before it runs, then installs it and restarts NexusVox (#408)
- Pip's what's-new tour keeps going after you click Show me, and you can reopen it later (#407)
- For extension authors: `on_file_transcribed` now receives the audio path of an upload (#410)

Upgrade notes
- Install over 1.0.1: run the new installer once by hand. From 1.0.2 on, updates install from inside the app. Your settings and recordings stay.
