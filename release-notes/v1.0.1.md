NexusVox 1.0.1 - clearer model downloads, easier exports and a friendlier Home

NexusVox is a Windows app that turns speech into text on your own PC. Version 1.0.1 is a polish release on top of 1.0.0: nothing big downloads unannounced, exports and speaker rows are easier to use, and Pip, the small companion on Home, tells you what changed after an update. NexusVox is source-available under the PolyForm Noncommercial License 1.0.0 and free for personal use.

Download and install
- Download `NexusVox-Setup.exe` from the assets below. It is per-user and needs no administrator rights.
- Requires Windows 10 (version 2004 or newer) or Windows 11, 64-bit.

What changed
- The speech model downloads only after you click Download, so nothing large arrives unannounced (#166)
- A new Export menu on recordings lists each format as its own row (#388)
- Every speaker in a meeting transcript has a row of their own (#346)
- One dark button set across the dashboard (#387)
- A Help link opens the online guide (#370, #377)
- A Copy diagnostics button next to Open log folder gathers what a bug report needs and sends nothing (#363)
- Pip lives on Home and shows a short what's-new popup once after an update (#380, #381, #382, #383, #397)
- Switching virtual desktops no longer plays the dictation start sound (#310)
- When the transcription server is unreachable, the log gets one line instead of a long traceback (#338)

Upgrade notes
- Install over 1.0.0: run the new installer. Your settings and recordings stay.
