NexusVox 0.7.0 - Parakeet on CPU, speaker detection and an extension API

This release lets Parakeet run in-process on CPU without Docker or a GPU, adds speaker detection and cleanup to file uploads, restyles the dashboard, and introduces the extension interface for optional packages.

Features
- Run Parakeet TDT 0.6B v3 in-process on CPU through ONNX (`onnx-asr`, int8) - no Docker, no GPU (#67)
- Optional speaker detection for file uploads with Parakeet (#55)
- Word timestamps from Parakeet for file uploads (#53)
- Optional LLM cleanup of file upload transcripts (#58)
- Progress display for long file uploads (#56)
- Extension interface for optional packages; extensions can mark exports unavailable and add upload actions (#63, #69)
- Aurora Precision theme for the dashboard (#48)
- Learn-from-edits now explains what it did and what it learned (#71)

Fixes
- The dashboard no longer scrolls sideways on narrow windows (#50)
- Learn-from-edits survives browser fields that are rebuilt while you edit (#71)

Docs
- CLA and Free vs Pro licensing documentation (#62)
- Pro marked as upcoming in the README (#65)
- Extension guide in `docs/EXTENSIONS.md` (#63, #69)

Upgrade notes
- Rebuild the Parakeet Docker container (`docker/Dockerfile.parakeet` and `docker/parakeet_server.py` changed): `cd docker && docker compose --profile parakeet up --build`.
- New dependencies `onnx-asr` and `onnxruntime`: run `pip install -e .` in your virtual environment.
- New database columns are migrated automatically on start.
- This is the first release with the extension API (`docs/EXTENSIONS.md`, API version 1).
